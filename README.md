# FinPlan Backend Sample

Демонстрационный фрагмент backend-части приложения **FinPlan** — сервиса для учёта личных финансов.

Репозиторий содержит очищенную sample-версию backend-кода и предназначен для демонстрации подхода к разработке, структуры проекта, работы с REST API, авторизацией, бизнес-логикой и слоями приложения.

> Это не полный production-репозиторий проекта. Из sample-версии удалены чувствительные данные, инфраструктурные конфигурации, production-настройки и часть функциональности.

## О проекте

**FinPlan** — приложение для управления личными финансами.

Основные возможности проекта:

- учёт счетов и валют;
- учёт доходов и расходов;
- категории транзакций;
- фильтрация и пагинация списка транзакций;
- финансовые планы;
- расчёт факта относительно плана;
- авторизация пользователей;
- интеграция с Google OAuth2;
- интеграция с Telegram-ботом;
- REST API для frontend-приложения.

## Что показано в этом репозитории

В репозитории представлены примеры backend-реализации:

- контроллеры REST API;
- DTO для запросов и ответов;
- сервисный слой;
- репозитории;
- модели предметной области;
- мапперы;
- валидация;
- обработка ошибок;
- конфигурация безопасности;
- JWT-авторизация;
- Google OAuth2;
- отдельный фильтр авторизации для Telegram Bot API.

## Архитектурный подход

Проект разделён на слои:

```text
controller   — REST-контроллеры
dto          — объекты запросов и ответов
service      — бизнес-логика
repositories — работа с базой данных
model        — доменные сущности
mapper       — преобразование model <-> dto
security     — авторизация, JWT, OAuth2, фильтры
validation   — валидация входных данных
